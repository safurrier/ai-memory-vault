# Productivity Module Setup

This module adds task management, daily routines, and weekly reviews to your vault.

## What's Included

### Task Files
- **Tasks.md** — Work tasks using an Eisenhower matrix (Urgent+Important, Big Rocks, Not Now, Done)
- **Personal Tasks.md** — Personal tasks using Now / Later / Done sections

### Skills
| Skill | What it does |
|-------|-------------|
| `/daily-start` | Morning boot-up: ASCII art, status board, today's focus, inbox check |
| `/daily-end` | Shutdown: capture work done, loose threads, sign-off art |
| `/status` | Quick "where am I?" — scannable task overview |
| `/week-start` | Monday: reprioritize Eisenhower matrix, pick #1 thing for the week |
| `/week-close` | Friday: weekly review, retro, stale note scan, reset for next week |
| `/weekly-status` | Generate exec-level status updates (5 Levels of Impact framework) |

## How to Enable

### Option 1: Via /personalize (recommended)
Run `/personalize` and say "yes" when asked about the productivity module. It handles everything automatically.

### Option 2: Manual setup
1. Copy task files to vault root:
   ```bash
   cp optional/productivity/Tasks.md .
   cp "optional/productivity/Personal Tasks.md" .
   ```

2. Copy skills to the skills directory:
   ```bash
   cp -r optional/productivity/skills/* .claude/skills/
   ```

3. Add task links to Home.md (in the Quick Access section):
   ```markdown
   - [[Tasks]] — Work tasks (Eisenhower matrix)
   - [[Personal Tasks]] — Personal tasks (Now / Later / Done)
   ```

4. Add the Productivity System section to CLAUDE.md (see examples/CLAUDE.md.work-context for reference).

## Task Conventions

### Work Tasks (Tasks.md)
- Tasks are markdown checkboxes: `- [ ] **Title** — details`
- When completing a task, append the date: `- [x] **Title** — details (2026-02-11)`
- The Eisenhower matrix has four quadrants — review weekly with `/week-start`

### Personal Tasks (Personal Tasks.md)
- Tasks have a category prefix: `- [ ] **[Home]** Task title`
- Common categories: `Home`, `Health`, `Code`, `Finance`, `Social`, `Learn`
- Freeform — make up new categories as needed

### Weekly Reviews
- Saved as `Weekly Review YYYY-MM-DD.md` with `type: review` frontmatter
- Generated by `/week-close` on Fridays
