# Vault Tour

Start by reading `AGENTS.md`, `Home.md`, and the user's actual MOCs. Claude Code is the beginner path: use `/tour` from its session after `/personalize`.

Keep each stop short and interactive: navigate Home and an MOC, explain capture into `staging/Inbox.md`, demonstrate how a note connects through `up:`, introduce URL reading, and show health checks. Ask before adding a capture or creating a note. Before every write, show the exact target and proposed content; wait for approval. Never turn an educational example into a surprise vault change.

When demonstrating migration, explain that `/obsidian-migrate` surveys, reports, and waits for approval. When demonstrating reading, explain provenance and accessible excerpts. Finish with a small command table and offer to stop or follow the user's chosen workflow.
