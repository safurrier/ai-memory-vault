# Obsidian Review and Literature Notes

Search for an existing title, author, URL, and close duplicate before proposing a new note. Use exhaustive text search and optional semantic search. Choose `review` for the user's interpretation of an external source and `literature` for retained source material; do not use a type as a quality judgment.

Present proposed type, title, parent, tags, source/provenance fields, duplicate results, and files to change. Wait for approval before writing.

Preserve supplied text and annotations. Clearly separate source-derived claims, existing vault context, assistant synthesis, and user-confirmed conclusions. If the source is incomplete, label the note as an accessible excerpt and do not claim full coverage. Never guess a redirect destination; retain the original URL when a destination cannot be verified.

After approval, add the note with minimal frontmatter, update its parent MOC, validate links, and report provenance and any unresolved extraction limit.
